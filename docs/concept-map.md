# Financial-modeling concept map

| Pipeline stage | Python work | Finance question |
|---|---|---|
| Retrieve | Request market or FRED data | What information is available? |
| Validate | Check dates, missing values, units, and prices | Can the data support the analysis? |
| Transform | Calculate returns, volatility, drawdowns, or ratios | What is economically meaningful? |
| Compare | Align dates and use consistent units | Are the securities truly comparable? |
| Visualize | Plot trends and macroeconomic regimes | What pattern is visible? |
| Interpret | Connect evidence to financial theory and limitations | What does the result mean—and what does it not prove? |

This is the same logic used behind professional dashboards, even when a bank obtains the raw data from a licensed platform such as Bloomberg. The visible chart is only the front end; data sourcing, validation, calculations, controls, and monitoring sit behind it.
