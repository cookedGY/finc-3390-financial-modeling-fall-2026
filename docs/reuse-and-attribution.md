# Reuse and attribution

Reusing code is normal. Reusing it responsibly is part of the job.

1. Prefer maintained libraries and official documentation.
2. Check the license before copying code.
3. Preserve copyright and license notices.
4. Link to the source and explain meaningful changes.
5. Never publish proprietary employer code, credentials, or restricted data.
6. Do not copy another student's solution or a professor's answer key.
7. Understand every line submitted for academic credit.

For a copied or adapted snippet, include a note such as:

```text
Adapted from: <project and source URL>
License: <license name>
Changes: <brief explanation>
Accessed: <YYYY-MM-DD>
```

When an idea—not code—comes from a source, cite the source in the notebook's interpretation section.
